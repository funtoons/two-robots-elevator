Entry for the [Two Robots in an Elevator](https://make.fun/c/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on [make.fun](https://make.fun/).

`main.py` writes one line of awkward small talk from one robot to another
in an elevator to `/output/entry.txt`. The line is a fixed literal: the
program is deterministic and offline — no randomness, no network, no clock —
so every run writes the same bytes.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
